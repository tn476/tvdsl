Грамматика Funny (LL(1), рекурсивный спуск)

Обозначения: [ x ] - необязательно, { x } - повторение, | - выбор, "x" - токен.

module      = item { item }
item        = IDENT params ( "=>" predicate [ ";" ] | funcRest )
params      = "(" [ varDef { "," varDef } ] ")"
funcRest    = [ "requires" predicate ]
              "returns" varDef { "," varDef }
              [ "ensures" predicate ]
              [ "uses" localDef { "," localDef } ]
              statement

varDef      = IDENT ":" type
localDef    = IDENT [ ":" type ]
type        = "int" [ "[" "]" ]

statement   = block | ifStmt | whileStmt | assertStmt | assumeStmt | assignment
block       = "{" { statement } "}"
ifStmt      = "if" "(" condition ")" statement [ "else" statement ]
whileStmt   = "while" "(" condition ")" [ "invariant" predicate ] statement
assertStmt  = "assert" predicate ";"
assumeStmt  = "assume" predicate ";"
assignment  = IDENT [ "[" expr "]" ] "=" expr ";"
            | IDENT "," IDENT { "," IDENT } "=" call ";"

condition   = orC [ "->" condition ]
orC         = andC { "or" andC }
andC        = notC { "and" notC }
notC        = "not" notC | condAtom
condAtom    = "true" | "false" | comparison | "(" condition ")"

predicate   = orP [ "->" predicate ]
orP         = andP { "or" andP }
andP        = notP { "and" notP }
notP        = "not" notP | predAtom
predAtom    = quantifier | formulaRef | "true" | "false" | comparison | "(" predicate ")"
quantifier  = ( "forall" | "exists" ) "(" varDef "|" predicate ")"
formulaRef  = IDENT "(" [ expr { "," expr } ] ")"

comparison  = expr relop expr
relop       = "==" | "!=" | "<" | "<=" | ">" | ">="

expr        = term { ( "+" | "-" ) term }
term        = unary { ( "*" | "/" ) unary }
unary       = "-" unary | primary
primary     = INT | call | IDENT "[" expr "]" | IDENT | "(" expr ")"
call        = ( IDENT | "length" ) "(" [ expr { "," expr } ] ")"

Приоритеты и ассоциативность (от низшего к высшему)

  ->                правая
  or                левая
  and               левая
  not               префиксный
  == != < <= > >=   неассоциативные
  + -               левая
  * /               левая
  унарный -         префиксный
